Architecture Overview

The Secure Messaging Blockchain System represents a zero-knowledge communication model. Rather than relying on central authorities to guarantee privacy and log integrity, this system uses verifiable cryptography at every tier:

Browser-Level RSA RSA-OAEP 2048-bit keys are compiled locally. The server is completely oblivious to user private keys.
Cryptographic Ledger Every transaction block includes the SHA-256 hash of its contents, linked to the previous block's hash.

System Roadmap

Phase 1 — Core Web Portal Completed

Flask application layout, SQLite integrations, and responsive Bootstrap styling with secure credentials hashing.

Phase 2 — End-to-End Cryptography Completed

Implementation of the Subtle Crypto Web API for local RSA-OAEP 2048-bit key pair orchestration and client-side payload encryption.

Phase 3 — Ledger Verification Chain Completed

A lightweight Proof-of-Work algorithm mining blockchain nodes in python, linking transaction hashes to prevent unauthorized modifications.

Phase 4 — IPFS Distributed Storage Completed

Storing encrypted payloads on interplanetary filesystem (IPFS) via Pinata to prevent data loss or server single-points-of-failure. Every message CID is pinned to the decentralized web with a local fallback cache.
