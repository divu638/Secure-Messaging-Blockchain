Process

How It Works

Six secure steps from authentication to verified message delivery

01
User Login

Authenticate with bcrypt-verified credentials and establish a cryptographically signed secure session token.

02
Generate Keys

RSA-OAEP 2048-bit key pair generated entirely client-side. Your private key never leaves your browser.

03
Encrypt Message

Message encrypted client-side using the recipient's public key before any network transfer. Server never receives plaintext.

Critical Security Step
04
Blockchain Record

SHA-256 Proof-of-Work mines a new block and cryptographically links it to the immutable ledger chain.

Tamper-proof
05
Secure Delivery

Encrypted ciphertext is delivered to the recipient alongside a blockchain verification receipt and digital signature.

06
Decrypt Message

Recipient decrypts locally using their private key. The server never sees plaintext — zero-knowledge guaranteed.
